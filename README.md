# Java Bank

Bu proje, Java ve Nesne Yönelimli Programlama (OOP) öğrenme sürecimde
geliştirdiğim basit bir banka yönetim sistemi uygulamasıdır.

OOP konusunu daha iyi öğrenmek ve kendimi yazılım geliştirme alanında
geliştirmek için müşteriler, banka ve hesap işlemlerini sınıflar kullanarak
modelledim. Proje; yeni müşteri ekleme, hesap açma, para yatırma, para çekme
ve müşterileri listeleme işlemlerini konsol üzerinden gerçekleştirir.

## Kullanılan Konular

- Java sınıfları ve nesneleri
- Yapıcı metotlar (constructor)
- Encapsulation ve getter metotları
- ArrayList kullanımı
- Metotlar ve koşullu ifadeler
- Konsol üzerinden kullanıcı etkileşimi

## Çalıştırma

```bash
javac *.java
java main
```

Bu proje, OOP öğrenirken pratik yapmak ve öğrendiklerimi gerçek bir senaryo
üzerinde uygulamak amacıyla hazırlanmıştır.
